          사용 팁 · 외부 AI에서 분석
          
① 버튼을 눌러 분석 요청문을 만드세요. ② 요청문을 복사하고 GPT/Gemini에 레퍼런스 이미지도 직접 첨부하세요. ③ 응답 JSON을 복사하여 위 ‘분석 JSON 붙여넣기’에 붙여넣고 ‘JSON 적용’을 누르세요. 이 버튼은 이미지를 전송하거나 옵션을 자동 변경하지 않습니다.

          
아래 요청문에는 현재 설정과 선택 가능한 값이 포함됩니다. 분석할 항목은 위 체크박스로 선택하세요. 선택하지 않은 항목은 현재 값을 유지하도록 요청합니다. JSON 코드 블록도 그대로 붙여넣을 수 있습니다.

02
비주얼 스타일

        
        
        
        

          사용 팁
          
‘렌더링 스타일’은 그림 전체의 질감을, ‘캐릭터 표현’은 비율과 귀여움 정도를 결정합니다. 둘은 분리해서 선택하세요.

        

      


      

        
03
캐릭터 형태

        
        
        
        
        

          사용 팁
          
영상 일관성을 위해 머리·눈·체형 수치는 한 번 승인한 뒤 가급적 잠그세요. 장면마다 이 값을 바꾸면 같은 캐릭터로 인식되기 어렵습니다.

        

      


      

        
04
Identity

        
        
        
        
        

          사용 팁
          
얼굴형·눈·귀·꼬리처럼 실루엣에 영향을 주는 특징은 Identity Anchor입니다. 영상 장면 프롬프트에서도 고정값으로 재사용됩니다.

        

      


      

        
05
색상 팔레트

        
        

          
          
        

        
사용 팁
팔레트는 캐릭터와 세계관을 연결하는 핵심 요소입니다. 한 작품에서는 4~6개의 대표색을 유지하는 것을 권장합니다.

      


      

        
06
의상 / 소품

        
        
        
        
사용 팁
대표 소품은 캐릭터 인식에 도움을 줍니다. 장면마다 바뀌는 소품과 ‘항상 유지할 소품’을 구분해서 관리하세요.

      


      

        
07
세부 표현

        
        
        
        
사용 팁
이 영역은 렌더링 스타일에서 자동 추천되도록 두고, 특별한 이유가 있을 때만 수정하는 것이 가장 안정적입니다.

      


      

        
08
성격 / 표정 / 동작

        
        
        
        
사용 팁
여기서 만드는 표정·동작은 Character Bible용입니다. 실제 영상 생성 때는 장면에 필요한 1~2개의 동작/표정 레퍼런스만 선택해 전달하는 것이 효율적입니다.

      


      

        
09
Character Lock

        

          
          
          
          
          
          
          
        

        
사용 팁
승인된 캐릭터는 핵심 Identity를 잠그고, 이후에는 ‘동작·표정·카메라’만 바꾸는 것이 장면 간 일관성을 가장 잘 유지합니다.

      


      

        
10
AI 수정 요청

        
        
        
사용 팁
입력한 요청은 선택 옵션과 함께 최종 프롬프트에 포함됩니다. 실제 수정은 GPT/Gemini가 수행하며, 이 페이지의 옵션값은 자동 변경되지 않습니다. 잠근 특징을 바꾸려면 해당 잠금을 먼저 해제하세요.

      


      

        
        

      

    

  


  
    

      

        
QUICK GUIDE

        
가장 효율적인 사용법

      

      
    

    

      
1
큰 방향부터 결정
캐릭터 유형 → 국가 → 시대 → 렌더링 스타일 → 캐릭터 표현 순으로 선택합니다.

      
2
Identity를 확정
실루엣, 얼굴, 눈, 귀, 꼬리, 비율, 대표색을 정한 뒤 Character Lock으로 잠급니다.

      
3
레퍼런스는 분석 후 재사용
마음에 드는 이미지는 매번 직접 따라 만들지 말고 스타일/비율/색상 옵션값으로 변환해 Style Profile처럼 재사용합니다.

      
4
Bible은 풍부하게, 영상 입력은 간결하게
캐릭터 Bible에는 Front/3·4/Side/Back, 표정, 동작을 보관하되 실제 영상 툴에는 장면에 가장 필요한 1~2장만 전달합니다.

      
5
영상에서는 고정값을 건드리지 않기
Identity·팔레트·의상은 유지하고 장면별로 Action, Emotion, Camera만 바꿉니다.

      
6
비용 절감 원칙
레퍼런스 분석과 Master Bible 생성은 캐릭터당 한 번만 하고, 이후 장면에서는 저장된 옵션과 선택된 1~2개 Reference를 재사용합니다.


      

        권장 표준
        
Character Bible 보관:
Front + 3/4 + Side + Back + Expressions + Motions

실제 영상 생성:
Reference 1 = Identity용
Reference 2 = 현재 각도/동작용
Text = 고정 Character DNA + Scene + Action + Camera
